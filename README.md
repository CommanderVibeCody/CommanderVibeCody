### 🎧 About me

I build things by **vibe coding**: pick a fun idea, put on some music, and iterate until it feels right.

- 🎮 Writing **games & interactive simulations** in Python / Pygame
- ⚙️ Rolling my own **physics** (Verlet integration, collisions, ricochets, drifting karts)
- 🧊 Pushing pixels with **hand-written software renderers** in NumPy (true 3D and Mode 7 pseudo-3D)
- 🧭 Visualizing **algorithms**: path-finding, splines, procedural terrain
- 🌱 Always tinkering with something new
